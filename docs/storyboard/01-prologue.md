# 序章分鏡：《死得好睇》

2026-10-29 · TASKS「故事 ②」· 依據 `docs/STORY.md`（世界、角色、輪迴的規矩）同開發者 10-29 的意見：第一稿的對白太密，「好似唔係俾人睇」；先分鏡、後對白、最後先出圖；開機喺**戲棚**。

## 呢章要做到乜

- **第一次開遊戲時出一次**，可以跳過；放映室重睇。八頁、38 格，標準速度約一分半至兩分鐘。
- **先鋪墊，後轉折。** 玩家睇完要知道：腥港係點樣的地方、9527 係邊個、佢點解會上車、佢點死、點解會重嚟。
- **只講 9527 自己知道的嘢。** 點解揀中佢、晶晶嗰場戲、金爺係邊個，序章唔講，留俾之後的輪迴同檔案頁。佢第一次見到金爺，只係戲棚高位上一個金牙閃一閃的人。
- **每頁只做一件事**，每頁至少一格反應或者停頓，唔係格格都交代資料。
- **9527 的動機喺序章尾先講出口：**「我想知……點解係我。」佢唔係為報仇，係想知道。之後三次破關就係佢慢慢知道的過程（`docs/STORY.md` §5）。
- **黑色幽默：** 佢第一晚死得好快，打手的反應係「……咁快收工？」：成晚的騷，開機冇幾耐就完。
- **埋伏筆：** 佢係因為「主角」兩個字先上車（第 3 頁）；真結局佢問閻王「下世可唔可以做主角？」（`docs/STORY.md` §7.8）。

- **頁：** 一個 16:9 畫面，幾格喺黑色底上逐格彈出（`docs/STORY.md` §11 的節奏）。
- **格：** 鏡頭（遠景／中景／近景／特寫）、畫面、表情、字或對白、停。「長停」係冇字、得聲效、或者要俾人笑或者吸收的格，停最少 2 秒。
