# 頭目入場

2026-10-30 · TASKS「故事 ④」· 依據 `docs/STORY.md` §3（角色）、§7.5（頭目戰）、§11（幾時出），`docs/art/CHARACTERS.md` §4（頭目的樣、主色、配件），同之前兩章定落的規矩（`01-prologue.md`、`02-every-night.md`）。

## 呢章要做到乜

- **第一次撞到先出成頁，之後只出第一格**（§11）。所以每頁第一格自己就要講得明：
  - 第一格唔講對白，淨係頭目大格加名牌。名牌由遊戲寫，中英對照。
  - 打第二次嗰陣，名牌格一閃大約 1.5 秒就開打。
- **頭目就係劇組。** 五個頭目係真人秀的五個部門，一睇道具就知做邊行：
  - 刀姐：分鏡紙。
  - 炮哥：炸藥箱。
  - 門神：場務對講機。
  - 長鏡：攝影機鏡頭。
  - 選角陳：試鏡相。
  - 名牌寫埋部門，好似片尾字幕咁。
- **五頁同一個版面：** 左邊頭目大格，右邊上面一格係佢一句，右邊下面一格係 9527 的反應。同層卡一樣，玩家第二次已經一見就知「頭目嚟喇」。長鏡同選角陳同場，嗰頁四格。
- **9527 的反應係笑位：** 頭目越惡，佢越平靜、越認真咁答錯重點（「第七個都幾好喎」「咁我算邊樣？」）。佢個樣照預設：呆、無辜，唔係型。
- **金爺喺呢度第一次露面。** 序章只係高位一個人影，層卡只見手、雪茄火同金牙。
- **照守之前的規矩：** 賭客只喺螢幕出現；圖入面唔畫字：分鏡紙冇字、炸藥箱留白、賭盤留白、試鏡相冇名。
