## 1. 而家的問題

**量度（2026-11-02）：** `npm run measure -- --mode danmaku --god --loot`，種子 101–105，五局全部通關，平均 9.1 分鐘。

- 頭目戰平均 **5–9 秒**，幾乎冇受傷；最長一次係第三層刀后，26 秒、受傷 24。
- 一局約 453 秒的戰鬥，頭目只佔 24 秒；一局 1,203 點受傷，頭目只佔 9 點。
- 頭目的血按命中次數計：4 下一格，第一、二層 4 格，第三層 5 格，即係 16–20 粒子彈，用咩槍都一樣。
- 同一個頭目一局可以撞幾次（種子 104 三層都係長鏡同選角陳）；第三層未固定係金爺。

**開發者打過的感覺（11-02）：** 冇子彈時間的反制。刀后舉刀嗰 0.5 秒有得踢、有得用鑊打返粒子彈，係唯一有特色的；重炮、鐵盾淨係繞去背脊射；長鏡同選角陳淨係靶。

## 2. 共通規則（全部頭目）

### 2.1 血量按傷害

- 頭目有 `hp`，子彈照每支槍的 `damage` 扣（散彈每粒照計）。血條照分格，但格只係刻度。
- 唔係子彈的嘢定一個固定傷害（第一版）：身邊爆炸 25、踢 5、鑊 10、踢人撞埋去 8。
- **反制另計**，一次大約係頭目血的一成半至兩成半（§2.4）。

| 頭目 | 血（第一版） | 備註 |
|---|---|---|
| 部門頭目 | 200 | 第二層 ×1.25 即 250，跟普通敵人每層加厚（`config.js` `ENEMY_HP.perStage`） |
| 長鏡＋選角陳 | 長鏡 110、選角陳 130 | 兩個人加埋 240，比一個人多：兩個人各有自己的反制 |
| 金爺 | 360 | 第一階段 240，第二階段 120 |
| 晶晶 | 「佢的戲」240 | 唔係佢條命（9527 唔殺佢），係佢場戲 |

**點計：** 每支槍每秒的傷害大約係雙槍 9、散彈 15、衝鋒槍 17、步槍 18、機槍 22。頭目郁得多、有遮擋，淨係射，一場大約打得出每秒 3 點左右，即係 200 血要成分鐘以上；識反制，三四次反制已經扣咗大半，就係 45 秒左右。

### 2.2 一局入面點樣排

- 第一、二層：喺四場部門頭目入面抽（刀姐、炮哥、門神、長鏡＋選角陳），**一局唔重複**。
- 第三層：**固定金爺**，喺戲棚。
- 真結局：已經通關兩次之後，打低金爺就入天光，再打晶晶（§5）。
- 每個頭目一個自己的片場（DECISIONS 2026-10-30）。片場先做玩法要的格局，美術跟 Godot。
- 入場：第一次撞到出成頁分鏡，之後只出名牌格約 1.5 秒；倒下蓋「某某　殺青」印。血條上的名改用劇本的名。
- 頭目房前面嗰波普通敵人：建議刪走（§6）。**待開發者定。**
- 全部快彈、紅線預告、彈幕有缺口：同普通房一樣。頭目照舊抓唔到做人盾，佢叫出嚟的手下抓得到。

### 2.3 每個頭目都要有

- **一句特色**：由劇本的身份同口頭禪嚟。
- **兩三招**：每招有預告，彈幕有缺口。
- **兩三個反制**（§2.4）：至少一個靠子彈時間，至少一個靠近身或者特技。
- **一個專屬花招**：入花招手冊（`src/codex.js`）。

### 2.4 反制（第二稿新加）

**反制**：頭目的招牌招式有一個好短的時機，玩家有意識去做一個動作，就將嗰招反過嚟打佢。

| 規矩 | 點做 |
|---|---|
| **子彈時間睇得到、做得到** | 時機全速大約 0.15–0.3 秒，高手唔使慢鏡都做到；開子彈時間（世界 ×0.2）就變成大約 1 秒，一般人做得到。子彈時間入面，個時機有一個閃光提示（刀柄、籌碼、瞄準鏡、炸藥包會閃），全速時冇 |
| **做成扣大血** | 一次約頭目血的一成半至兩成半，仲有僵直，跟住係一個打得入的空檔 |
| **回專注** | 反制成功回 0.25 專注（同處決一樣，`FOCUS.executeRefill`）：用啱時機開慢鏡，慢鏡自己還返，唔係成場開住 |
| **唔鎖血** | 唔反制都打得死，只係慢（大約成倍時間）；機制係幫你，唔係關閘 |
| **每個頭目唔同** | 刀姐靠接同擲（佢的刀）；炮哥靠佢的炸藥喺佢身邊爆；門神靠閃身借力撞；長鏡靠對鏡；選角陳靠近身踢槍；金爺靠射籌碼；晶晶靠喺佢的射燈下搶鏡 |
| **有名、有分、入手冊** | 每個反制一個 Style 名同分，第一次做到點亮手冊 |
| **失手有代價** | 時機錯咗就係食咗嗰招 |

遊戲而家已經有的反制，係呢套的基礎：用子彈打中子彈（DEFLECT）、鑊揮嘅頭 0.25 秒打返子彈（HOME RUN、狙擊彈 GONG）、踢返敵人的手榴彈、半空射爆手榴彈（AIRBURST）、旋轉避斬、子彈時間飛撲、踢翻枱。

## 3. 四個部門頭目

冇第二階段。每個 45 秒左右（識反制），血 200（第二層 250）。

### 3.1 刀姐（動作指導，酒樓大廳）——「你點死，我度好晒。」

**特色：佢度好晒點殺你，但你可以拆佢的招，仲可以用佢的刀。** 每一招之前，畫面一角彈出一格分鏡草圖做預告（「第三種：飛刀」「第七種：衝刺斬」）。

| 招 | 做法 |
|---|---|
| 飛刀 | 高台上紅線 0.4 秒，兩排快刀，第二排插喺第一排之間（而家有）；中唔到你的飛刀會釘喺枱、牆、地上 |
| 衝刺斬 | 衝埋嚟停喺 1.7 米外，舉刀 0.5 秒，斬（而家有） |
| 刀陣 | 落台時一圈快刀，有缺口（而家有） |

| 反制 | 點做 | 效果 |
|---|---|---|
| **接刀**（子彈時間） | 飛刀擦身（擦彈的 0.5 米）嗰下撳 G，就接住把刀；再撳 G 擲返佢 | 中一把 20，佢踉蹌；一排三把接齊擲返係「原刀奉還」 |
| **執刀** | 釘咗喺枱、牆、地上的飛刀，行過去撳 G 拎起，擲佢（同擲鑊一樣） | 中一把 15 |
| **拆招**（近身） | 佢舉刀嗰 0.5 秒：踢，佢彈開、空檔長咗（而家有）；或者喺最後一刻旋轉穿過佢嘅斬，轉到佢背後 | 旋轉穿過：佢背脊空 1 秒，嗰一秒傷害 ×2 |

- **專屬花招：** 原刀奉還 RETURN TO SENDER（一排飛刀接齊擲返）。
- **可選：「冇度過」**（第一稿）：佢記住你上次點避，下次封住嗰種避法；你用佢未見過的方法避開，佢呆一秒。可以第二步先加。
- **同而家比：** 招式照用；加接刀、執刀、旋轉穿過；飛刀變成你的武器。

### 3.2 炮哥（爆破組，貨櫃碼頭）——「今晚冇假炸藥。」

**特色：成個片場都係佢的炸藥，你的反制就係令佢的炸藥喺佢身邊爆**（「點解……爆嘅係我？」）。同刀姐分得開：刀姐拎佢的武器打佢，炮哥係借佢的爆炸，時機同位置最重要。

| 招 | 做法 |
|---|---|
| 轉輪機槍 | 起轉 0.8 秒（槍管轉、聲、紅線），之後一扇快彈掃過去（而家的掃射同扇） |
| 拋炸藥 | 一次拋兩三個炸藥包，每個落點一個紅圈（而家的迫擊砲改） |
| 引線 | 按引爆器，地上的引線燒向油桶同炸藥箱，一個接一個爆；冇炸藥的嗰條路係缺口 |

| 反制 | 點做 | 效果 |
|---|---|---|
| **半空引爆**（子彈時間） | 炸藥包啱啱離手、仲喺佢頭頂嗰段（拋物線頭三分一）射中佢 | 喺佢頭上爆：35，鋼板歪咗，正面都打得入 2 秒 |
| **踢返**（近身） | 跌喺你附近的炸藥包，爆之前踢返去佢度（而家踢得返敵人的手榴彈） | 喺佢身邊爆：35 |
| **卡彈**（近身，搏命） | 機槍起轉嗰 0.8 秒，衝（或者飛撲）入佢 2 米內踢支槍 | 機槍卡住、子彈帶爆：40，僵直 2 秒；遲咗就正正食晒成扇 |

- **專屬花招：** 自食其果 OWN GOAL（炮哥俾自己的炸藥炸到）。
- **同而家比：** 鋼板、掃射照用；迫擊砲改做可以反制的炸藥包；加卡彈。

### 3.3 門神（場務，海底隧道口收費廣場）——「清場！生人死人都唔准過！」

**特色：佢唔追你，佢守住出口；佢又重又硬，衝起嚟停唔到，所以你的反制係「借力」**：閃身令佢撞埋收費亭，或者喺佢插盾嗰下撬開個盾。

| 招 | 做法 |
|---|---|
| 盾撞 | 舉盾 0.7 秒，衝 7 米（而家有）；衝嘅時候會慢慢轉向跟你 |
| 撼盾 | 盾撼落地，一條裂地沿行車線衝向你（紅線 0.7 秒），要打橫避；之後個盾插喺地 1.4 秒 |
| 清場 | 對講機一叫，兩個盾牌保安由隧道口並排推出嚟（人牆） |
| 左輪 | 你喺遠處，佢由盾邊開三槍（而家有） |

| 反制 | 點做 | 效果 |
|---|---|---|
| **鬥牛**（子彈時間） | 佢盾撞衝到最後 0.3 秒先打橫閃（太早閃佢會轉向跟住你），佢衝過龍撞落收費亭或者欄杆 | 撞到：30，卡住 2 秒，背脊向你 |
| **撬盾**（近身） | 盾插喺地嗰 1.4 秒，踢盾邊 | 盾跌落地：20，佢冇盾 3 秒（正面都打得入） |
| **借人牆** | 抓一個盾牌保安，推佢撞門神 | 門神僵直 1 秒（而家「踢人撞埋去」照計） |

- **專屬花招：** 鬥牛 MATADOR（門神撞落收費亭）。
- **同而家比：** 正面免疫、盾撞、左輪照用；由「追住你」改做守門；加鬥牛、撬盾、叫保安。

### 3.4 長鏡＋選角陳（攝影指導＋選角，攝影棚）——「企定，我要個特寫。」「千揀萬揀，揀中你。」

**特色：一個揀位，一個影。** 選角陳追住你、用散彈同試鏡相將你趕埋「企位」；長鏡伏喺高處，紅線就係佢的取景框，鎖住你一秒就開槍。**兩個都唔再係靶**：長鏡可以對鏡反殺，選角陳可以踢走佢支槍，兩個人又可以互相誤傷。

| 招 | 做法 |
|---|---|
| 選角陳：散彈 | 追住你，三條紅線 0.6 秒，散彈之後再一扇快彈（而家有） |
| 選角陳：下一位 | 擲一疊試鏡相，相落地變企位；你踩住企位，長鏡即刻鎖定 |
| 長鏡：對焦 | 紅線跟住你；鎖住 1 秒，一槍（72 米每秒、40 傷害，而家有） |
| 合招 | 紅線衝鋒（而家有） |

| 反制 | 對 | 點做 | 效果 |
|---|---|---|---|
| **對鏡**（子彈時間） | 長鏡 | 佢紅線鎖住你嗰 1 秒，面向紅線沿住條線射返去（射中瞄準鏡） | 35，佢失焦 2 秒，要落嚟換位（喺地面打得入） |
| **鑊打狙擊彈** | 長鏡 | 有鑊喺手，鑊揮嘅頭 0.25 秒打中佢粒子彈（而家的 GONG） | 35 |
| **踢槍**（近身） | 選角陳 | 佢三條紅線出咗嗰 0.6 秒，衝（或者飛撲）入 2 米內踢佢 | 散彈射上天、試鏡相散一地：30，僵直 1.5 秒 |
| **搶鏡**（子彈時間） | 選角陳 | 長鏡鎖住你、選角陳又喺你同長鏡之間嗰陣，最後一刻閃開 | 長鏡打中選角陳（而家的 CROSSFIRE）：40 |

- **專屬花招：** 對鏡 SCOPE SHOT（射中長鏡的瞄準鏡）。
- **待定：** 劇本寫長鏡伏喺攝影棚天台，但遊戲的規矩係大家喺同一水平交火（DECISIONS 2026-10-22）。兩個做法：天台做成房一邊的天橋，同一水平照打得到；或者佢平時喺天台、換位時先落地面。對鏡兩個做法都做得到。

## 4. 金爺（監製兼莊家，戲棚，第三層固定）

**特色：佢做莊。每開一盤之前，佢彈一隻金色籌碼上半空，呢個就係你的反制：喺半空射中隻籌碼，子彈彈去佢度，嗰盤作廢。** 第二階段佢自己都玩呢招，一次掟幾隻籌碼，你要搶喺佢前面射。

口頭禪同分鏡：「呢一鋪，我做莊。」「全腥港都買你死。」（入場）；「開大！」（第二階段）；「莊家……點會輸？」（倒下，一隻金牙飛出嚟，接結局 B）；9527「今晚我做莊。」

### 4.1 片場：戲棚

序章、層卡、入場頁、三次通關都喺度，格局要同圖對得上：

- **台（北半邊）：** 台中間一張長賭枱，金爺坐喺後面（莊家位）；兩邊衣邊係出入口。
- **大螢幕（北牆的竹架上）：** 賭盤，字由遊戲寫。
- **台下（南半邊）：** 一排排空凳，係矮掩體。
- **竹架（東西兩邊）：** 牆跑的牆。
- **貴賓位（台的東北角高處）：** 金色欄杆圍住，一條窄樓梯；晶晶戰先用（§5）。
- **射燈、燈籠：** 金爺戰係氣氛，晶晶戰係機關。

### 4.2 第一階段「做莊」（血 240，約 30 秒）

金爺坐喺賭枱後面。張枱**唔係擋晒**：打中佢只係傷害減半（第一稿係擋晒，即係鎖血，刪咗）。每開一盤之前，佢用手指彈一隻金色籌碼上半空（約 0.8 秒先跌返落手），Action 叔讀出呢一盤。三盤由種子抽次序：

| 盤 | 做法 | 缺口 |
|---|---|---|
| **買大細** | 台下凳區左右兩半，一半亮「大」、一半亮「細」；骰盅搖 1.5 秒；開盅前 0.6 秒揭出係大定細，竹架上的槍手掃輸嗰半邊 | 另一半邊 |
| **派彩** | 金爺由枱後面舉起金色左輪，一扇快彈（紅線 0.6 秒） | 扇入面缺兩粒 |
| **收注** | 衣邊行出兩三個打手 | 抓一個做人盾 |

| 反制 | 點做 | 效果 |
|---|---|---|
| **截糊**（子彈時間） | 籌碼喺半空嗰 0.8 秒射中佢 | 子彈由籌碼彈去金爺（同鑊彈去最近的敵人一樣，`bullets.js` `ricochet`）：40，嗰盤作廢 |
| **掀枱**（近身） | 走埋去踢翻佢張賭枱（遊戲本身的翻枱） | 15，籌碼飛起擋視線，佢冇遮 3 秒、全傷害 |
| **推人落注** | 抓一個收注的打手，推佢撞金爺 | 金爺僵直 1 秒 |

- 截糊係呢場的主菜：每盤都有一次機會，射中就扣大血兼唔使避嗰盤。
- **晶晶：** 入場頁佢挨住金爺膊頭；戰鬥時佢企喺貴賓位睇住，唔參與。**待開發者定。**

### 4.3 轉場「開大！」（血剩三分一）

單格分鏡（`04-defeats.md` 第 5 頁第 1 格）約 1.5 秒：甩西裝、單手掀起賭枱，籌碼同銀紙爆上半空。返到遊戲時籌碼銀紙仲喺度跌，遮視線 2 秒；張賭枱打橫喺台上，變咗一幅牆。

### 4.4 第二階段「開大」（血 120，約 20 秒）

冇咗張枱。佢落台追你，成身金鏈、兩支金色手槍，佢自己都玩籌碼：

| 招 | 做法 |
|---|---|
| 雙槍 | 近距離連射，紅線短（0.4 秒） |
| 全部押上 | 一次掟三四隻籌碼上半空，之後逐隻射，子彈由籌碼彈落嚟，由唔同角度射你（每隻籌碼一條紅線，0.5 秒） |
| 梭哈 | 剩最後一成血，佢企定喺台中間，向四周放三圈快彈，每圈的缺口轉位 |

| 反制 | 點做 | 效果 |
|---|---|---|
| **搶莊**（子彈時間） | 全部押上：喺佢射之前，你先射中半空的籌碼 | 每隻彈去佢度：15；搶齊晒係「搶莊」：佢呆 2 秒 |
| **截糊** | 佢逐隻射之前，每隻籌碼一樣射得 | 同上 |
| **梭哈之後** | 撐過三圈 | 佢喘氣 2 秒，全傷害 |

- **倒下：** 金牙飛出嚟（結局 B 執嗰隻）→「莊家……點會輸？」→ 天光（§5.1）。

### 4.5 專屬花招同用得着的程式

- **專屬花招：** 截糊 INTERCEPT（射中金爺彈上半空的籌碼）；搶莊 HOUSE BUSTED（全部押上的籌碼全部搶晒）。
- **程式：** `bullets.js` 鑊的反彈（打中就彈去最近的敵人）做籌碼；`Bulwark` 的正面計算做賭枱（改做減半，唔係擋晒）；`Duo` 的手下同兩招互相讓（`mayTell`）做收注同全部押上；`Gunner` 的掃射同扇做派彩同梭哈。
- **可選：** 第一稿的「Style 越高傷害越大」（賭客改買你）。唔係鎖血，但同截糊有啲重疊，**待開發者定**。

## 5. 晶晶（女主角，戲棚貴賓位，真結局）

**特色：佢唔識打，但呢個舞台係佢的。** 佢企喺貴賓位的射燈下面，揸住咪叫「燈光！保鏢！」，燈光、機關同保鏢就出手。**佢最憎有人搶佢鏡頭**：你企入射燈的光，機關就衝你嚟，但你喺光入面打得漂亮，就係搶佢的戲。血條係**佢的戲**，唔係佢條命：9527 唔殺佢。打到最尾，佢頭頂射燈的鈎俾反彈子彈打甩，射燈撞暈佢。

口頭禪同分鏡：「呢招我見過。」（9527）、「燈光！保鏢！」、「今晚，主角係我！」（入場）；「區區一個臨記，」「你憑啲咩！？」、「……今晚唔係。」（倒下）。

### 5.1 幾時出：天光

已經通關兩次之後，打低金爺就入天光：

| 第幾次打低金爺 | 天光發生乜 | 點做 |
|---|---|---|
| 第一次 | 大螢幕甩螺絲（嗒、嗒、嗒），跌落嚟壓死 9527 | 過場（`06-clear-1.md`） |
| 第二次 | 9527 避開大螢幕，晶晶由背後開槍 | 過場（`07-clear-2.md`） |
| 第三次起 | 9527 避開大螢幕，轉身避開晶晶，晶晶逃上貴賓位 | 過場（`08-true-ending.md` 第 1 頁），之後開打 |

建議三次都係過場：打完十分鐘先嚟一下避唔到就 NG，好傷。**待開發者定。**

### 5.2 第一階段「燈光！保鏢！」（佢的戲 240 → 剩三分一，約 30 秒）

9527 喺台上，晶晶喺貴賓位（佢唔打，射佢亦都唔會扣）。樓梯有保鏢守住。

| 機關 | 做法 |
|---|---|
| **射燈**（三枝） | 喺台上掃；照住你 1 秒就鎖定，下一樣機關衝你嚟（`Heli` 的探照燈） |
| **沙包** | 吊喺竹架上；地上紅影 0.8 秒之後跌落嚟 |
| **活門** | 台板一塊塊打開（紅框 0.8 秒）；跌落去受傷，由台邊爬返上嚟 |
| **保鏢** | 黑西裝，兩三個一組由衣邊出（打手、盾牌保安）；照住你的射燈會話佢哋知你喺邊 |

佢的戲點樣扣（**全部都扣，冇一樣係關閘**）：

| | 點做 | 扣 |
|---|---|---|
| 射爆射燈 | 射燈個燈頭 | 15 |
| 打低保鏢 | 一個 | 8 |
| **搶鏡**（反制，子彈時間） | 俾射燈鎖住嗰陣，喺光入面做一個花招擊殺（慢鏡擊殺、飛撲擊殺、人盾、反彈……）。大螢幕的賭客轉咗睇你 | 40 |
| **踢沙包**（反制，近身） | 沙包跌落嚟嗰下（紅影縮到最細，子彈時間入面閃）踢佢，沙包飛去最近的保鏢或者樓梯 | 25，撞中的保鏢即倒 |
| **活門陷阱**（反制） | 活門紅框亮嗰陣，引保鏢衝埋嚟，最後一刻飛撲過個窿 | 跌落去的保鏢每個 15 |

- 呢段的題目：**光入面危險，但光入面先搶得到鏡**。匿喺暗處安全但慢；敢企入光、打得靚，先快。同 9527 搶戲正好呼應。
- 佢的戲剩三分一：樓梯的保鏢散晒，晶晶嗌「你憑啲咩！？」，9527 行上貴賓位。

### 5.3 第二階段「亂開槍」（剩三分一，約 15–20 秒）

貴賓位窄（約 8 × 5 米）、近，一邊係金色欄杆，晶晶企喺另一頭的射燈下面。

- **晶晶亂開槍：** 手袋槍連射，冇紅線、唔瞄你，打晒落欄杆同牆。劇本寫「一槍都唔中」：建議照劇本，佢的子彈永遠偏開你一米以上（擦彈照計，回專注）。**待開發者定**：要唔要會中但傷害細。
- **最後兩個保鏢：** 守喺樓梯頂，係呢段真正的危險；打低每個扣 8。
- **反制：欄杆反彈**（子彈時間）：佢的子彈打中金色欄杆，欄杆嗰一點會閃 0.3 秒；喺佢閃嘅時候射中嗰一點，你的子彈就沿住佢嘅反彈線飛上去打中射燈的鈎：每下扣 25，射燈晃一晃、「噹」一聲。
- **佢的戲扣到零**，無論最後一下係乜，都係射燈連鈎跌落嚟撞暈佢，接倒下分鏡（`08-true-ending.md` 第 2 頁），「晶晶　殺青」。劇本的「最後一擊係反彈」由畫面保證，唔使玩家一定要用反彈先打得完。
- 直接射晶晶：唔扣（佢企喺強光入面一閃就避開）。9527 唔殺人，呢個係規矩。

### 5.4 專屬花招同用得着的程式

- **專屬花招：** 搶鏡 SCENE STEALER（喺射燈下做花招擊殺）；殺青 THAT'S A WRAP（欄杆反彈打中射燈鈎）。
