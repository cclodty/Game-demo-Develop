# 劇本初稿：《一夜成名》

2026-10-29 · TASKS「故事 ①」· 第二稿。第一稿係開發者答咗十二條引導問題之後寫；第二稿跟開發者 10-29 的回覆改：主角叫 **9527**、幫派叫**金牙幫**、城市叫**腥港**、結局 B 改由**極難通關**觸發、主角識打係因為**真人秀輪迴咗好多次**、過場的出法交 Claude 定（§11）。其他名、對白、頁數仍然係第一稿，可以改。

呈現方式：漫畫格逐格彈出，一格一個畫面、一句廣東話（`docs/REDESIGN.md` §2 的「漫畫分格」）。

## 1. 一句講晒

臨記 9527 喺片場得罪咗金牙幫老大要捧的女星，被揀做地下真人秀《一夜成名》的獵物，全腥港的富豪落注佢幾時死、點樣死。佢死咗。閻王同玉帝慶祝第一千億個準備投胎的鬼，送佢一份大禮：重過死前嗰一晚，直至佢「死得心甘命抵」為止。

**語氣：** 港產片咁爽，夾黑色幽默。地府係政府櫃位，大禮係商場抽獎，賭盤係直播節目。

## 2. 世界與輪迴的規矩

- **城市：** 腥港（SING KONG），架空的港澳式夜都市，名係香港的諧音，一聽就知（開發者 10-29）。
- **生死冊寫咗佢今晚死，改唔到；改得到的係點樣死。** 呢句係成個故事的核心，亦都係支柱一「打得漂亮比打得多重要」的講法。
- **大禮條款：** 「重過死前一晚，次數不限，直至閣下死得心甘命抵為止。受條款及細則約束。」
- **一晚＝一局：** 黃昏開機 → 深夜埋位 → 天光前殺青（三層）。
- **死咗：** 返地府投胎櫃位，閻王蓋「NG」印，再由黃昏開始。
- **天光：** 嗰晚收工，返櫃位等閻王判：心甘未？抵未？兩樣都係，輪迴先完。
- **記憶：** 9527 冇飲孟婆湯，所以記得每一晚。金牙幫啲人唔記得，但重拍得越多（階梯越高），佢哋越「似曾相識」：開始收埋殺氣（冇紅線）、加裝備（詞綴）。
- **點解一個臨記識打：** 因為真人秀輪迴咗好多次（開發者 10-29）。第一晚佢乜都唔識：新手熱身就係第一晚，學慢鏡、抓人擋子彈、翻枱。之後每死一次，就學識一樣。觀眾唔記得，以為每晚都係新一集，所以收視一晚高過一晚。
- **慢鏡：** 子彈時間係大禮附送的「慢鏡功能」，專注值就係套餐餘額。只係講法，玩法唔變。

**9527 這個名：** 致敬周星馳電影裏的僕人編號，華語觀眾一睇就知。一個數字唔係真人的名，冇問題；但只係借個編號：唔用嗰套戲的其他角色名、對白、場口，9527 的樣都唔可以似任何真實演員（CLAUDE.md 第 8 條）。外地玩家睇唔出都唔緊要：臨記冇名、得個編號，本身已經講得通。

尾聲：金爺都死咗，喺地府攞籌，排第一千億零一號。閻王：「大禮？派晒喇。」

## 6. 結局 B：引火

開發者的提議：輪迴中可以揀為兩個幫派引火，佢哋忙住開片，就冇時間搞真人秀。

- **觸發：** **極難通關**（開發者 10-29）。現時即係「芭蕾」難度（`src/rules.js`）；F⑥ 階梯做好之後，由嗰張卡定「極難」係邊一級。任何一次極難通關都係結局 B；其他難度通關就行結局 A 的下一段。
- **故事點解係極難：** 極難嗰晚，成個金牙幫出晒嚟追 9527。佢索性帶住成幫人衝過街界，入咗 925 的地盤，再將金爺跌落的金牙掟埋過去。
- **收尾：** 兩幫人開片，劇組全部被調去打仗，冇人拍戲。天光，9527 坐喺天台食住菠蘿油睇落街；流彈飛過。閻王：「抵你死。」9527：「都算心甘。」輪迴都完，但閻王蓋的係另一個印。
