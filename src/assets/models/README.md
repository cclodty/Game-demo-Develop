# 角色模型

目前使用的模型（皆為 Quaternius 製作，CC0 授權，可免費商用、不需署名；取自 Poly Pizza）：

| 檔案 | 原始名稱 | 內容 |
| --- | --- | --- |
| `player.glb` | Adventurer | 24 個動作：持槍待機與瞄準、前後左右跑步、走路、死亡、受擊、翻滾等 |
| `zombie.glb` | Animated Zombie | 5 個動作：待機、走、跑、撲咬、爬行（沒有死亡動作，倒地由程式處理） |

把模型檔放在這個資料夾，重新建置後就會取代方塊暫用人形：

| 檔名 | 用途 |
| --- | --- |
| `player.glb` | 主角 |
| `zombie.glb` | 喪屍 |

- 也接受 `.gltf`（需為單一檔案、內嵌資料）與 `.fbx`。
- 模型需要有骨架與動作（至少待機、走或跑；最好有死亡與攻擊）。
- 載入時會自動縮放到 1.8 公尺、腳底貼地。動作依名稱自動辨識（idle、walk、run、death、attack、punch 等）。
- 走路與跑步動作的設計速度會在載入時自動量測（依腳著地時往後滑的速度），播放速度跟著角色實際速度調整，腳步不會打滑。
- 主角若有瞄準姿勢（例如 Idle_Gun_Pointing），上半身固定播瞄準、下半身播移動；有前後左右跑步動作時會依方向混合。
- 自動辨識不準、模型面向不對或想截取動作片段時，到 `src/entities/characterAssets.ts` 的 `MODEL_CONFIG` 調整。
- 只放授權允許的素材（例如 CC0），並在 `docs/m1/README.md` 的資源清冊記下來源。
