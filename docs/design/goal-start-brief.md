## 使用前準備

1. 將《末日生存遊戲企劃初稿》《第一個可玩版本：三人逃難序章》《製作資源準備計畫》及本文件放在家中可讀取的工作資料夾。
2. 確認家中 Godot 是否可啟動，以及遊戲專案要放在哪裡。若已存在專案，接續該專案並先檢查現況。
3. 已確認鍵鼠、360°自由瞄準及整個人物連續平滑轉身。本版草稿改採GDScript、3D暫用操作場與固定傾斜鏡頭，再加入像素風呈現小樣；正式美術規格待測試。
4. 啟動時由使用者設定需要的算力預算；本文件不預填數字。

Goal 的官方說明強調成果、範圍及可檢查的完成證據。[Using Goals in Codex](https://developers.openai.com/cookbook/examples/codex/using_goals_in_codex)

## 本 Goal 的暫用操作提案

| 操作 | 候選輸入 |
| --- | --- |
| 移動 | WASD |
| 瞄準 | 滑鼠位置，水平360°連續角度；人物連續轉身 |
| 射擊 | 滑鼠左鍵 |
| 子彈時間 | 空白鍵按住使用，放開停止 |
| 暫停 | Esc |
| 重設測試 | 畫面中的重設按鈕 |

按鍵與子彈時間的按住方式都是原型提案，可在試玩後調整。

## 回家後第一輪驗證清單

- [ ] 記錄真正使用的 Godot 版本、渲染設定及專案位置。
- [ ] 從乾淨啟動進入測試場，畫面及中文提示正常。
- [ ] 沿牆走動、轉角與反向移動，鏡頭朝向不旋轉。
- [ ] 滑鼠繞角色一整圈，人物及槍械連續轉向；慢轉與快速轉向皆可用。
- [ ] 面向一側，向另一側移動並射擊；能後退及橫移作戰。
- [ ] 面向不同方向射擊；擊中敵人與牆有正確結果。
- [ ] 近距離、貼牆、鏡頭移動及像素呈現切換後，準星與射擊位置仍可理解且一致。
- [ ] 消耗子彈及生命，看到數值和回饋改變。
- [ ] 連續使用至子彈時間耗盡，再用部分回復量啟動。
- [ ] 子彈時間中失敗或重設，確認時間倍率和狀態復原。
- [ ] 完成一輪實際互動試玩；若工具無法完成則保留未勾選。
- [ ] 保存可接續的專案、操作說明、檢查結果及下一步紀錄。
