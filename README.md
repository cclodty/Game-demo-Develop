# Bullet Ballet 子彈芭蕾

俯瞰式（top-down）子彈時間射擊遊戲原型，用 Three.js 製作。靈感來自 *My Friend Pedro*：
慢鏡、雙槍分離瞄準、旋轉閃避、反彈子彈、踢擊，以及鼓勵「打得好看」的 Style 計分。

敵人一波一波湧上來，每一波比上一波更多、更兇；每清 3 波就轉移到下一個場景
（霓虹天台 → 脈衝夜店 → 七號碼頭 → 議事亭前地，然後循環），開始畫面可以選擇起點。
除了預設的雙槍，還可以撿到 6 種武器。

## 執行

遊戲是純靜態網頁，沒有建置步驟；Three.js 已放在 `vendor/` 內，不需要網路。
因為使用 ES modules，必須經由 HTTP 開啟（直接雙擊 `index.html` 不行）：

```bash
python3 -m http.server 8000
# 或
npx http-server -p 8000
```

然後打開 <http://localhost:8000>。需要滑鼠 + 鍵盤（暫不支援手機觸控）。

推送到 `main` 時，`.github/workflows/pages.yml` 會把整個 repo 部署到 GitHub Pages
（repo 的 Pages 設定需選擇 *GitHub Actions* 作為來源）。

## 玩法重點

- **子彈時間**：世界減速到 20%，玩家只減速到 55%，所以你相對變快。慢鏡時畫面去飽和、
  只有發光的子彈和激光保留顏色；音效降調、音樂像錄音帶一樣變慢。
- **敵人會預告**：開槍前會用激光瞄準，激光越亮代表越快開槍。敵人會預判你的走位，
  直線逃跑不安全，要在子彈飛來時改變方向。
- **每顆子彈都是實體**：看得見、躲得開，也可以用自己的子彈把它射下來（DEFLECT）。
- **平底鍋**：射中後子彈會自動反彈到最近、看得見的敵人（RICOCHET）。踢它會飛起來。
- **紅色油桶**：會爆炸、可連鎖引爆；也可以踢過去當保齡球。
- **玻璃牆**：一槍就碎，敵人看得穿玻璃。
- **Style 分數**：基本擊殺分 × 連擊倍率（最高 x16）。慢鏡擊殺、旋轉擊殺、分離瞄準擊殺、
  反彈、爆炸、踢殺、保齡球（STRIKE!）、多殺、遠距、近距、子彈擦身（CLOSE CALL）
  都有額外分。被擊中會斷連擊。每清一波回滿血並補 Focus。

| 場景 | 特色 |

| 霓虹天台 NEON ROOFTOP | 下雨的天台、直升機坪、玻璃溫室、樓梯間和從天台邊爬上來的敵人 |

| 議事亭前地 LARGO DO SENADO | 按實景比例重建的澳門議事亭前地（白天）。由新馬路經噴水池廣場、約 10 米闊的窄段一直到板樟堂前地，長 148 米；敵人從新馬路兩端和各條橫巷湧入。掩體是熟食檔、石花槽、街燈、巴士站和停泊的的士，熟食檔旁的石油氣罐會爆炸 |

### 鏡頭

預設是 **45° 側俯視**。按 **V** 輪流切換三種鏡頭，選擇會記住：

- **俯視**：每張地圖自己的角度（一般約 59°，議事亭前地約 72°）。
- **45° 俯視**：鏡頭壓低到 45°，仍然從南面望。
- **45° 側俯視**：45° 加上從西南角斜望，類似等角視角。WASD 會跟着鏡頭轉，W 永遠是「畫面向上」。

鏡頭壓低後，擋在鏡頭和主角之間的牆、掩體和樓宇會被挖空。

### 議事亭前地

模型來自同一個 repo 的議事亭前地量體研究（`claude/practical-archimedes-ay1ycf` 分支的 `senado/`，1 單位 = 1 米）。
遊戲只取廣場一帶：

- 模型逆時針轉 38°，讓廣場在畫面上由下往上延伸，新馬路在最下方。
- 遊玩範圍是 52 × 148 米，外圍再保留 30 米樓宇作背景（93 棟，約 8 萬個三角面）。
- 範圍內 34 棟樓宇的 OSM 輪廓直接用作碰撞體（多邊形，不是方塊）；噴水池的池身是掩體，
  外圈下沉台階會讓人物真的走低 0.48 米。
- 樓宇很高（17–25 米），所以這張地圖的鏡頭比較陡，而且鏡頭和主角之間的樓宇會被挖空。
- 白天燈光、跟隨鏡頭的陰影，曝光和泛光按日光另外設定。
- 除了熟食檔、街燈等街道設施，也放了其他關卡的障礙物：木箱、紅油桶、氣罐、玻璃屏風、
  混凝土路障、電箱和報紙亭。
- 廣場上有一群白鴿：有人走近、開槍或爆炸時會一起飛走，過一會再降落到離玩家較遠的地方；
  子彈時間中會慢動作振翅。

更新模型後重新抽取：

```bash
node scripts/senado-extract.mjs <senado 資料夾的路徑>
```

會覆寫 `src/senado/model.js`（原封不動複製）、`src/senado/data.js`（裁切後的資料）和
`src/senado/assets.js`（地磚和窗戶貼圖）。範圍和旋轉角度在 `src/senado/transform.js`。

### 人物比例

人物改成真人比例，與議事亭前地模型的比例人一致：約 1.78 米高、肩寬約 0.46 米，碰撞半徑 0.3 米。
所有尺寸集中在 `src/characters.js` 的 `BODY`，改這裡就會套用到主角和全部敵人。

每張地圖有兩個**金色武器台**，每一波開始時會刷出一把武器。

### 3D 模型

主角、敵人、武器、道具、環境物和議事亭前地的地標都可以換成高質量 3D 模型。沒有模型的繼續用方塊版，所以可以逐件替換。

- **[`assets/SPEC.md`](assets/SPEC.md)**：比例尺寸與交付規格，以及轉用 Unity、Unreal、Godot 的須知。
- **[`assets/PROMPTS.md`](assets/PROMPTS.md)**：71 件物件的參考圖和 3D 模型提示詞。
- **`assets/asset-list.json`、`assets/maps/*.json`**：引擎中立的物件清單和地圖佈局。
- **處理流程**：母版放進 `assets/source/<id>/`，執行 `npm run assets` 就會生成網頁版並用在遊戲裡。
- **人物動作**：只需要 idle、run（最好加 death）；瞄準、側行、後退、踢、翻滾仍由遊戲控制，雙手用 IK 握住遊戲自己的槍。
- **網址參數**：加 `?models=off` 可看回方塊版，加 `?use=hero-b` 可切換同一物件的不同版本。

### 武器

雙槍彈藥無限（30 發彈匣，要換彈）。其他武器都是撿來的，彈藥用完就自動切回雙槍；
同時只能帶一把特殊武器，走過同款武器會補彈藥。

| 武器 | 來源 | 特性 |
| --- | --- | --- |
| 雙槍 DUAL PISTOLS | 預設 | 可以分離瞄準 |
| 雙衝鋒槍 DUAL SMG | 武器台、THUG 偶爾掉落 | 射速極高、散布大，可以分離瞄準 |
| 散彈槍 SHOTGUN | 武器台、SHOTGUNNER 掉落 | 8 顆彈丸，近距離一槍把人轟飛，有後座力 |
| 突擊步槍 ASSAULT RIFLE | 武器台、RIFLEMAN 掉落 | 準、快、每發傷害較高 |
| 狙擊槍 SNIPER RIFLE | 武器台 | 一槍斃命，子彈穿透最多 5 個目標（COLLATERAL 加分）；右鍵瞄準鏡 |
| 榴彈發射器 GRENADE LAUNCHER | 武器台 | 拋物線榴彈，落地或撞到敵人就爆炸；自己被炸到傷害減少 |
| 機槍 MINIGUN | BRUTE 必定掉落 | 240 發彈幕，但拿著時走得比較慢 |

### 敵人

| 類型 | 特性 |
| --- | --- |
| THUG | 手槍，最常見 |
| SHOTGUNNER | 散彈，喜歡貼近 |
| RIFLEMAN | 三連發，遠距離、預判較準 |
| BLADE | 沒有槍，衝過來砍你 —— 用旋轉閃避或踢回去 |
| BRUTE | 第 4 波起出現，又大又硬，機槍會追著你掃射 |

## 程式結構

```
index.html        HUD / 選單 DOM，importmap 指向 vendor/three
style.css         介面樣式
src/
  main.js         Game：主迴圈、時間縮放（子彈時間、hit-stop、kill-cam）、攝影機、事件
  config.js       所有手感參數（速度、子彈時間倍率、射速、鏡頭）
  player.js       玩家：移動、武器槽與射擊、旋轉、踢、分離瞄準、受傷/死亡
  weapons.js      玩家武器數值、掉落表、榴彈
  pickups.js      地上的武器、武器台刷新、拾取與交換
  enemies.js      敵人種類、武器與 AI 狀態機（移動 → 瞄準 → 射擊 → 恢復）、掉落武器
  bullets.js      子彈：逐段碰撞、反彈、擦身判定、互相抵消
  level.js        載入地圖：掩體、玻璃、油桶/氣罐、平底鍋、武器台、出生點、燈光、雨
  maps.js         四張地圖的資料（掩體座標、道具、出生點）和各自的佈景與動畫
  senado/         議事亭前地：轉換參數、抽取出來的模型程式、資料和貼圖
  ambient.js      環境生物（白鴿群）
  cutaway.js      把鏡頭和主角之間的物件挖空的 shader 補丁
  nav.js          網格 A* 尋路
  fx.js           粒子（InstancedMesh）、地面血跡、閃光燈、衝擊波、激光
  postfx.js       Bloom + 子彈時間調色 shader（去飽和、色差、暗角、漣漪）
  audio.js        WebAudio 合成音效與背景音樂，會隨時間縮放降調
  hud.js          HUD、Style 分數欄、橫幅、準星、畫面外敵人箭頭
  waves.js        波次編排與出生預告
  score.js        分數、連擊、最高分（localStorage）
  characters.js   方塊風人物模型、可替換的武器模型與動畫
  asset-manifest.js  3D 模型清單：人物、武器、道具、環境、地標、材質的尺寸、面數、提示詞
  models.js       載入 assets/models/ 的模型，按碰撞盒縮放擺放道具
  skin.js         讓有骨架的人物模型跟隨方塊骨架：播動作、轉身、雙手 IK 握槍
  models-index.js 由 scripts/assets.mjs 生成：已處理好的模型列表
  textures.js     程序生成的貼圖（地板、木箱、貨櫃、圍欄、窗戶、霓虹招牌）
vendor/three/     Three.js r186（MIT）及所需的 addons（postprocessing、GLTFLoader、SkeletonUtils、meshopt）
assets/           3D 模型：source/ 放高質量母版，models/ 是處理後的網頁版；規格、提示詞、清單、地圖佈局
scripts/assets.mjs  把母版減面、縮貼圖、壓縮成網頁版，並合併分開存放的動作
scripts/asset-docs.mjs  生成 PROMPTS.md、asset-list.json/.csv、maps/*.json
```

想調手感，先看 `src/config.js`；玩家武器在 `src/weapons.js`；敵人數值在 `src/enemies.js`
的 `TYPES` / `WEAPONS`；波次節奏在 `src/waves.js`。

新增地圖：在 `src/maps.js` 加一個物件放進 `MAPS` 陣列即可。座標以地圖中心為原點，
x 向右、z 向鏡頭（南）；掩體寫成 `[x, z, 寬, 深, 高, 材質]`。
