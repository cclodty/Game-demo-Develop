## 2. 美術聖經（一頁）

**定調一句：** 一個架空港澳夜都市的街頭動畫：鮮色、霓虹、濕的地、街頭時裝；打鬥是舞蹈，鏡頭是漫畫分格。

**主參考：** 都市潮流動畫（絕區零的街區與轉場、女神異聞錄的 UI）。三張參考圖放 `docs/art/reference/`（**開發者填**：一張街景、一張角色、一張 UI）。

**色盤（第一版）：** 每間房兩三隻主色（例：茶樓 朱紅＋墨綠、碼頭 鐵灰＋橙燈、夜店 紫＋青）；全遊戲固定四隻功能色：**敵人快彈** 黃白、**慢大彈幕** 粉紅、**玩家子彈** 青白、**紅線** 紅。功能色不許被房的主色撞到（房的主色避開黃、粉紅、青、紅）。

**角色比例與剪影規則：** 頭身 6–6.5（動畫比例，不是積木人的 5）；俯視看到的是頭頂、肩、手臂、腳步，所以**每種敵人一個一眼認得的輪廓和一隻主色**：盾牌手的方盾、大隻佬的闊肩、帶頭大佬的長褸、擲彈兵的背囊、精英的大帽或傘。玩家是全場唯一的白色（外套可換色，但淺色為主）。這是玩法需要，不是美術喜好。

**賽璐璐規格：** 兩段色階（亮、暗）加一條邊光；陰影偏紫藍、不偏灰；描邊 1.5–2 像素、深色不黑；地面不描邊（子彈要清楚）；子彈和紅線不受燈光影響、永遠全亮。

**特效與鏡頭：** 擊殺鏡頭改成漫畫分格（畫面切兩三格、黑白一幀衝擊幀、狀聲字）；速度線在滑鏟、飛撲、牆跑時由畫面邊緣進來；子彈時間入場是畫面一抹色偏和粒子；彈道有手繪感（粗細不均的尾巴）。

**UI：** 斜切版面、大字、動態轉場（進房、選卡、結算都是一下子掃入）；中文為主、英文顯示標籤（`雙槍 DUAL PISTOLS` 的配對不變）；字體兩款：一款粗黑做標題，一款圓體做內文（**開發者填**：授權可商用的字體）。

**鏡頭：** 不變（固定俯視、`VIEWS` 幾個視角、cut-away）。

## 6. 一局與局外

- **三層、十分鐘**；每層 3–4 間房 + 頭目房；層完三選一卡。
- **兩道門**（F③）：每個出口兩道門，門上標房和獎勵；輸入記錄入揀門。
- **自選挑戰與獎勵**（F②）：

| 挑戰 | 做到 | 獎勵（局內，第一版） |
|---|---|---|
| 不開槍 | 整間房沒有開過槍 | 一張卡（四選一）|
| 不用慢鏡 | 沒有進過子彈時間 | 專注上限 +1 格 |
| 無傷 | 沒有中過彈 | 一條命 |
| 限時 | 20 秒內清房 | 一支特別武器 |

- **階梯**（F⑥）：通關解鎖第 1 級，每級一個固定修飾（第一版：1 敵人 +10%、2 專注回得慢、3 頭目多一階段、4 沒有紅線、5 詞綴每房兩個、6 卡只剩兩選一、7 一條命、8 快彈 +10%、9 沒有缺口保證、10 全部），記「你去到第幾級」。
- **基地**（H⑦）：一個場景（天台屋或茶餐廳）：揀裝備和外套、花招手冊、檔案、試槍場、解鎖變體、階梯。
- **解鎖表（第一版）：** 卡池初始 8 張，每過一級階梯或一個挑戰解 1–2 張；主題房的夜晚版本過日間版的挑戰解；新武器在某間房做到某個花招解；變體掛階梯。

## 9. Godot 工程規劃

- **版本與設定：** Godot 4 最新穩定版；GDScript，`static typing` 開（`gdlint` 當 lint）；Compatibility 渲染器；物理步 120 Hz（`physics_ticks_per_second`），邏輯全部在 `_physics_process`。
- **目錄：** `data/`（SPEC §8 輸出的 JSON：房、敵人、武器、卡、波次、規則）、`scenes/`、`scripts/`、`shaders/`、`tests/`、`tools/`（機械人、量度）。
- **確定性：** 一個種子 RNG（`RandomNumberGenerator` 實例，不用全局 `randf`），邏輯和效果分流（照 `rng.js` `fork`）；輸入記錄照 `.bbr` 格式（控制位元、瞄準點、鏡頭 yaw，每步一行只記變化）；重播是測試的根。
- **測試：** gdUnit4（或 GUT）單元測試；headless 機械人（`godot --headless -s tools/bot.gd`）跑一局出一層一行的數字；Xvfb + 軟件渲染截圖；CI：lint、測試、Web 與 Linux 輸出。
- **Web 輸出：** coi-serviceworker（GitHub Pages）或 itch 的 SharedArrayBuffer 開關；G⑦ 在開發者的機器驗證 macOS。
- **效能門檻：** 500 粒子彈 120 Hz 不跌幀（MultiMesh 繪製）；不夠才把子彈步進落 GDExtension。
- **資料流：** JS 倉 `npm run assets:docs` 輸出的 JSON 是 Godot 的輸入；改設計先改 JS 的資料再輸出，直到 G⑤ 之後才以 Godot 的 `data/` 為準。
