# 子彈芭蕾 Bullet Ballet — 規劃書第三版：彈幕

2026-10-16 初版 · 2026-10-22 第二版 · **2026-10-26 第三版**：開發者多輪重玩之後，與 Claude 四輪問答重新設計整個遊戲。第二版原文在 `docs/ROADMAP-2026-10-22.md`（TASKS.md、DECISIONS.md、GOAL.md 引用的 §編號指向它）；這一版是現行的。

## 1. 摘要

**開發者 2026-10-26 的結論：** 撇除地圖，最好玩的是**子彈時間、花俏的動作、多工具用法、地圖互動**；加了彈幕之後開始形成閉環。但彈幕試驗（10-23 起，照《Enter the Gungeon》做）的子彈是 6–11 m/s 的慢彈，與想像中不同：想像中是**街機那種非常高的彈速，整個螢幕都是非常多、非常快、相對密集的子彈**，靠子彈時間先看得清；**人盾擋彈**是壓制子彈擴散的方法。

**兩個發現（Claude 查過程式與紀錄）：** 街機敵人的彈速由第一日（10-12）起從未改過：手槍 20、步槍 28、散彈 17、機槍 18、無人機 24 m/s；開發者記得的「初初那個非常高的彈速」就是街機這一套，彈幕試驗是另一套。另外彈幕試驗 ⑦ 的三種重火力敵人全部標了 `heavy`，抓不到做人盾（`enemies.js` `holdable`）：想用人盾壓制彈幕，現在的模式正正做不到。

**九個決定（DECISIONS 2026-10-26）：**

| 題目 | 決定 |
|---|---|
| 彈速 | **快慢混合**：主力是街機現有敵人，照用街機彈速 20–28 m/s 和街機子彈的樣子，打密些、人多些；少數精英射慢的大彈幕做「牆」（退役的環形／螺旋／扇形手回歸），兩種子彈的樣子不同 |
| 公平感 | 紅線 + 開火前發光 + **每波火力必有缺口** |
| 子彈時間 | 照舊一條專注值表，靠擊殺／擦彈／處決賺回來；數字再調 |
| 人盾 | 升級做**資源**：抓住的時限 1.5 → 4.5 秒；按種類有不同效果；推出去會撞開子彈、撞散隊形；敵人見到自己人被抓會轉去射側面 |
| 一局 | **三層，每層 3–4 間房 + 層尾頭目，約 10 分鐘**；每層完揀一張風格卡（動作卡與慢鏡卡混入三選一）；工具照舊在房內撿 |
| 房間 | 主題房串連；舊的七張實景地圖**全部重做成主題房，實景比例不要**，每間房一個只有那裏才有的互動 |
| 頭目 | 現有的人類頭目（刀后、重炮手、鐵盾、長槍手＋散彈手）改入房、彈幕化；載具類不上場 |
| 舊模式 | 街機、無盡、每日、澳門一夜**收起**：程式和測試留下，標題畫面不顯示，`?mode=` 仍進得去 |
| 支柱 | 「真實澳門是賣點」不再成立，太局限；澳門只作區域特色（美術方向），不是支柱 |

**定位一句話：** 用子彈時間在滿屏快彈之間跳舞；工具、人盾、房間都是解法。澳門味道是美術方向。

**完工的定義（改寫）：** §9 的五個階段（彈幕手感、人盾資源、一局骨架、頭目入房、主題房）做完，加上模型審視與手機 ②，遊戲就算完工。

## 3. 設計支柱

往後每一個新功能都用這四條原則衡量；不符合任何一條的，就不做。

1. **打得漂亮比打得多重要。** 分數、評級、解鎖都獎勵花式和多樣性，不獎勵躲在角落打點射。
2. **子彈時間是解題工具，不是無敵按鈕。** 慢鏡用來看清楚彈幕找缺口，再用動作和工具解；不是每波必開的保命符。
3. **彈幕是題目，一定有缺口；工具、人盾、房間互動都是解法。**（取代第二版的「真實澳門是賣點」。）每一波火力都保證有一條走得過的路，看得出（紅線、發光）；沒有路時翻枱、人盾、滑鏟、飛撲就是路。每間房一個只有那裏才有的互動。
4. **一局十分鐘，每一局都有得著。** 結束時帶走一個評級、一段片段、一步解鎖的進度。

**三條線**不變：每張卡都要答得出「玩家多了一個什麼漂亮的解法」：**打得精彩**、**地圖會說話**、**不開槍也能打**。

**澳門**降為美術方向：房間是澳門常見的場所（茶樓、大排檔、廣場、後巷……），有區域特色就好；不用實景比例、OSM、量體研究；不用真實店名、品牌、人物、事件。

## 4. 彈幕的規格

**快彈主力。** 街機現有的敵人（打手、步槍手、散彈手、大隻佬、刀手、盾牌手、炸彈客、擲彈兵、飛仔、帶頭大佬……）入房，照用街機的彈速（20–28 m/s）和子彈的樣子（加色發光、有尾巴）。密度來自三件事：房內沒有「瞄準牌」（`enemies.js` `requestToken`：有 `floor` 的模式全部直接得）、射擊的冷卻按模式收緊（`config.js` 新 `HELL.fireMul`）、同場人多（`HELL.maxAlive`）。數字全是第一版，由開發者試玩定。

**慢大彈幕精英。** 彈幕試驗 ③ 的環形手、螺旋手、扇形手回歸做精英（第二層起，每間房最多一個）：6–8 m/s 的慢彈，實心粉紅的樣子照舊，做「牆」逼你走位；快彈在牆之間穿過來。重火力三種（機槍手、排槍手、霰彈手）的招式保留，子彈改成快彈的速度和樣子，做「壓制者」。

**公平感三件：**

1. **紅線**：每個開火的敵人照舊先拉紅線瞄準（街機的 `aimTime`，由難度和關數縮放）。
2. **發光**：開火前站定、身上發光（重火力的 `glow` 借給全部敵人）。
3. **缺口保證**：同一間房的火力按拍子輪流（`HELL.beat`），任何一個邏輯步，玩家 6 米內的子彈之間至少有一條 ≥ 1.2 米闊的路（闊過判定點 0.22 米和身體 0.3 米）；沒有路時，下一個要開火的人等一拍。測試用幾何驗。

**擦彈**照舊（貼身 0.5 米每粒 +0.02 專注值、GRAZE 10 分）；**傷害**每粒照街機（打手 20、步槍 16、散彈每粒 13）。

**對面陣地**（原彈幕試驗 ⑧）併入快彈入房：敵人入房後去離入口遠那邊的開火位（房間模板 `posts`），躲在掩體後開火；你迫近 4 米或掩體被打爛就換位。

## 5. 人盾資源

| 項目 | 第一版 |
|---|---|
| 抓得到誰 | 全部地面敵人：`holdable` 只排除無人機、頭目、未入場、已被抓 |
| 時限 | `humanShield.hold` 1.5 → 4.5 秒（他死了或你放手就完） |
| 代價 | 照舊：走 ×0.6、只開左槍、不能滑鏟、旋轉、飛撲 |
| 擋彈 | 照舊：前方 ±60° 打向你的子彈歸他，每粒扣他 1 血（大隻佬吸最多） |
| 推出去 | 照舊 24 m/s 約 6 米；**新**：飛行中照擋子彈（`hostage` 旗標跟人走），撞倒的人同被踢飛一樣倒地，撞倒 ≥ 2 人 = SHIELD BOWLING |
| 敵人反應 | 有 `strafe` 的敵人（步槍手、散彈手）見同伴被抓就橫移到你側面 ±60° 外再開火；打手照射（打中人盾） |

**按種類的效果：**

| 人盾 | 抓住時 | 推出去 |
|---|---|---|
| 打手、刀手、飛仔 | 照舊 | 照舊 |
| 炸彈客 | 背心燈急閃，不會自爆 | 0.4 秒後爆（自己人的爆炸，CHAIN） |
| 盾牌手 | 他的盾向前，正面 ±70° 免疫，不扣血；側面照舊 | 連盾撞人，撞倒的人多一倍距離 |
| 大隻佬 | 走 ×0.4，吸彈量照他的血（第一關 30） | 撞倒一排（撞 ≥ 3 人 = SHIELD BOWLING ×2） |
| 帶頭大佬 | 他的手下（`escort`）和同房打手停火，直到放開 | 放開後手下亂一陣（現有的 `waver`） |
| 重火力三種 | 他的槍沿你的面向開火，子彈算你的（HOSTAGE FIRE） | 照舊 |
| 擲彈兵、狙擊手、盾牌手以外的槍手 | 照舊 | 照舊 |

無人機飛着、頭目太大：抓不到。每種一個測試。

## 6. 一局的骨架

- **三層**，每層由種子抽 3–4 間房（第一層第一間固定是茶樓），層尾一間**頭目房**；一層當一關計難度（`ENEMY_HP`、`RAMP` 按層升）、一首歌。
- **每層完三選一風格卡**（§8）。
- **工具只在房內撿**：鑊、點心車、石油氣罐、枱、敗人掉的槍；沒有武器台。
- **評級**照舊三項：Style 分、**無傷房數**（取代無傷波數）、用時（8 分鐘滿分、16 分鐘零分）。
- **每日挑戰**之後回來：同一天同一層同一套卡（種子＋日期），等骨架穩定。
- 機械人（`npm run measure`）打完三層約 10 分鐘，量度工具一層一行。

每間房 22 × 15 米左右、一個畫面看得完、平地一層；一句「只有那裏才有的互動」是房間的身份；**沒有獨特互動的房不做**。實景比例、OSM、量體都不用，只要味道。

## 8. 風格卡

每層完三選一，只改玩法、不加數值；卡是資料（`src/cards.js`），記入重播（`PLAY_REV` +1）。卡池兩類混入，首批六張：

| 類 | 卡 | 做什麼 |
|---|---|---|
| 動作 | 滑鏟反彈 | 滑鏟中從頭頂飛過的子彈反彈回去 |
| 動作 | 人盾引爆 | 人盾推出去落地時爆（半徑 2 米） |
| 動作 | 枱面反彈 | 翻起的枱把子彈彈回去，不會爛 |
| 慢鏡 | 擦彈反彈 | 慢鏡中擦過的子彈反彈 |
| 慢鏡 | 擊殺慢鏡 | 每次擊殺自動入慢鏡 0.5 秒，不耗表 |
| 慢鏡 | 深慢鏡 | 慢鏡世界 0.2 → 0.1，表耗 ×1.6 |

之後每階段加兩三張；成就解鎖新卡（解鎖的是選擇，不是威力）。

## 10. 風險與對策

| 風險 | 後果 | 對策 |
|---|---|---|
| 範圍 | 五個階段二十多張卡 | 一張卡一天、有「這次不做」；四條支柱 |
| 沒有試玩者 | 快彈的公平感只有開發者一個人判斷 | 密度、彈速、缺口闊度全部在 `config.js HELL`，數據面板即時調；測試量「同場子彈數」「每秒開火數」「缺口」，每張卡附數字 |
| 快彈太難 | 20–28 m/s 的子彈在正常時間一秒飛過整間房 | 紅線、發光、缺口保證三件一起做；子彈時間照舊是常備工具；傷害每粒照街機、血 100 有回復 |
| 繪製次數 | 同場人多：子彈已合併繪製（彈幕試驗 ①），人未 | 每間房 ≤ 400 次繪製由地圖測試守住；人多到超出就按材質合併人物 |
| 舊內容過時 | 舊地圖、舊模式、舊頭目的程式和測試拖慢每張卡 | 不急着刪：E 每做完一間房刪那張舊地圖；舊模式收起不刪 |
| 真實地點的敏感性 | 房間仍有澳門味道 | 不用實景、店名、品牌、人物、事件；敵人是虛構幫派 |
| 一人開發的節奏 | 幾星期沒有可見進展就會停下來 | 每張卡合併上線一次，開發者即玩 |
