## 接手時必須保留的最新決定

- **視覺：**2.5D像素風，固定觀看方向的俯視鏡頭，鏡頭跟隨角色移動。
- **操作：**鍵盤與滑鼠；玩家只控制主角，360°自由瞄準，整個人物也要連續平滑轉身；移動與瞄準分開，可邊退邊射。
- **目前技術提案：**優先用3D人物與場景，搭配像素材質和低解析度呈現。這是為滿足平滑轉身的製作建議；正式造型、渲染規格與手感需原型驗證。
- **已被取代的提案：**早期「先做2D、角色用4方向圖」不再是目前的原型起點。不要將人物轉身或射擊角度限制為4／8方向。
- **子彈時間：**有限度使用，可在未等待完整冷卻結束時再啟動。能量消耗與回復是原型提案；按住或切換、倍率、數值仍可調整。
- **遊戲節奏：**只有遊玩時推進時間；可安排日程後跳過繁複過程。輕度生活求生、冒險準備與槍械戰鬥並存。
- **世界：**玩家親自步行探索相連地區。村落自行工作與發展，玩家可保持自由人、作有月度貢獻的居民，或逐步成為領導者。
- **開場：**喪屍危機爆發一天後，先在家使用有限物資準備撤離；熟悉的民用仿人型AI同行，途中與神秘NPC互救後結伴。
- **AI能力：**未經改造，戰鬥能力基本與主角相同，較硬朗且不會感染；不能擅自加入軍用或超級戰鬥能力。
- **感染與風險：**人類感染不可逆，神秘NPC於開局用未知藥劑使主角取得抗體；夥伴救援失敗會永久失去，重要劇情人物會提前逃離。具體判定仍待設計。
- **劇情細節稍後再定：**姓名、人設、台詞、兩次互救細節、藥劑真相和時點等不是操作原型的前置條件。文件中的情節例子沒有自動成為正式劇情。

## 製作條件與下一個成果

已知家中電腦為 Windows、64GB RAM、RTX 4090，Godot 已安裝。初期使用免費工具、暫用素材與現有圖像生成額度。

回家後核對 Godot 完整版本與路徑、專案位置、系統與顯示設定，以及助手能否啟動並實際操作 Godot。不要假設目前對話所在電腦的路徑、檔案或工具權限已同步到家中。

完整遊戲的第一個可玩版本是「三人逃難序章」。建議先做其 M1：一個小型3D操作場，含主角、測試敵人、一把槍、牆與障礙、基本介面及子彈時間。驗證360°轉身、瞄準、邊退邊射、牆體阻擋、重設，以及像素呈現下的可讀性，再接三人跟隨和事件。

尚未確認的Godot版本、具體按鍵、動作規格、渲染解析度、子彈時間數值等，都應保持提案或待測試狀態。已確認方向見各文件的標記；使用者後續更正優先。
