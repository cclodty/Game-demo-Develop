## 1. 一句講晒

標題就係過場漫畫嘅第 0 頁：主視覺斜切成幾格彈入，粗明體標誌「啪」一聲蓋落去；選單係四條斜切黑條，用片場用語（開機、收工）配英文標籤；游標係場務姐塊場記板，揀嘢「啪」一聲；角落嘅場記板寫住玩家玩過幾多晚（TAKE 數）。撳「開機」直接接第一張層卡「黃昏・開機」。

舊標題（JS 原型）係網頁思路：一塊置中嘅面板塞晒模式、地圖、規則、每日挑戰同七個按鈕。第二代淨係留四樣，其他搬去佢哋應該喺嘅地方（§5）。

## 3. 標誌

- 中文「子彈芭蕾」用粗明體（港產片海報嘅感覺），微微向右斜，紅色硬陰影；英文「BULLET BALLET」用窄體大寫、字距開闊、金色，後面拖一條金線。
- **用字體排，唔交 AI 畫字**（AI 畫中文字會錯）。試做頁用 Google Fonts 嘅 Noto Serif HK Black 同 Bebas Neue 頂住；正式版要開發者揀兩款可商用的字體（REDESIGN §2：一款粗黑做標題、一款圓體做內文），Steam 版要有授權。
- 開場「蓋」落去：由 135% 縮返 100%，畫面震一下（0.2 秒）。

## 6. 狀態同轉場

| 狀態 | 發生乜 | 時間 |
|---|---|---|
| 開場 | 黑畫面 → 主視覺逐格彈入（同過場一樣：由所在方向飛入、0.9 倍放大到 1 倍，每格相隔 0.2 秒）→ 暗位淡入 → 標誌蓋落、震一下 | 約 1.7 秒；撳任何掣跳過 |
| 撳任何掣 | 左下角「撳任何掣 PRESS ANY BUTTON」閃（1.6 秒一下）；第一下掣決定提示列顯示鍵盤定手掣 | 等到撳為止 |
| 選單 | 四條黑條由左邊逐條掃入（相隔 0.06 秒）；場記板停喺「開機」 | 0.5 秒 |
| 移動 | 揀中嗰條變白底黑字、向右推、橙色硬陰影；場記板跟住移、塊板「啪」一聲合埋；短「嗒」聲 | 0.14 秒 |
| 開機 | 場記板大「啪」、白閃、畫面震、大字「啪！」→ 淡入第一張層卡 | 0.5 秒後接層卡 |
| 設定、收工 | 設定頁由右滑入（0.28 秒）；收工框由下浮起（0.24 秒）；返回鍵關 | |
| 閒置 | 射燈掃、塵飄；之後（H⑥ 有音樂時）標題曲播 | |

減少動態（作業系統設定）時：唔彈、唔震、唔掃，只係淡入淡出。

## 7. 輸入

- **鍵盤：** ↑↓ 或 W／S 揀，Enter／Space／J 確定，Esc／Backspace／K 返回，←→ 喺設定頁改數值。
- **滑鼠：** 指住就揀中，撳就確定；喺設定頁或收工框外面撳＝返回。
- **手掣（標準佈局）：** 十字掣或左搖桿揀，A／Start 確定，B 返回。Godot 用 focus neighbour 同 `ui_*` 動作；Steam Input（I 組）再對應。
- **提示列跟最後用嘅裝置換：** 鍵盤顯示「↑↓ 揀　ENTER 確定」，手掣顯示「✚ 揀　Ⓐ 確定　Ⓑ 返回」（A 綠、B 紅）。

## 10. Godot 做法（建議）

- `scenes/ui/title.tscn`：`Control` 做根，跟畫面縮放；`ArtPanels`（每格一個 `Polygon2D`，貼主視覺做 texture，多邊形用來源像素，同過場共用一套切格資料）；`Logo`（兩個 `Label`，Theme 字體）；`Menu`（`VBoxContainer` 入面四個 `Button`，斜邊用 `StyleBoxFlat` 嘅 `skew`）；`Slate`（游標）；`AnimationPlayer` 做開場同轉場。
- 選單資料寫喺 `data/ui/title.json`（項目、中英文、去邊個場景、第一次開嘅規則），唔寫死喺場景度。
- 開機嘅轉場直接 `change_scene` 去第一張層卡嘅過場（過場系統讀 `docs/storyboard` 輸出嘅資料）。
- 截圖測試：1920×1080 同 1280×800 各一張；手掣走一次選單（headless 送輸入事件）。
