## 技術上要守的
- 遊戲邏輯只用 game.rng，不用 Math.random；特效用 utils.js 的 rand。邏輯在 120 Hz 固定步裡運行（main.js 的 updatePlay → 各系統的 update(dt)），新系統放進 logic，不放 present。一局留下的東西要在 resetWorld／resetProps 重設（test/seed.test.mjs 會抓）。
- 輸入只從每步的 game.cmd（StepInput）讀。鍵位可改（settings.js、input.js 的 ACTIONS）：邏輯只看控制碼，新動作盡量重用現有控制；真的要新控制就加在 input.js BUTTONS 的最後並加進 ACTIONS，記錄格式版本號跟着升，重播測試要過。
- 互動件、門、水邊、工具、舞台、頭目停留點都是地圖資料（maps.js），行為寫在系統（fixtures.js、level.js、enemies.js、boss.js）。不寫「只有這張地圖才有」的程式；一張地圖獨有的東西也要用資料表達。
- 頭目：Boss 子類登記在 boss.js 的 BOSSES，地圖用 `boss: { kind, … }` 選；共用的是 Boss（血條、HIT／BOSS DOWN 橫幅、BOSS 獎勵、剪輯、finish）。改頭目波次（每個場景一次）時 waves.js 的 bossWave／isFinal、main.js 的轉場、routeText、音樂 level 2、test/route.test.mjs、test/boss.test.mjs、test/arcade.test.mjs 都要跟着；test/helpers.mjs 的機械人懂得打貨車後門和重炮背後，整局街機測試（15 分鐘上限）必須仍然通關。
- 掩體改變時（門開關、鐵閘落下、招牌落地、木箱碎）要 nav.buildRect 局部重建並讓 hasLOS／raycast 看到；敵人的路徑會自己重算。
- 敵人的新狀態放進現有狀態機，沿用 requestToken、blind、kick、stun 等機制；黑暗、煙霧、網都用 blind／stun 表達。
- 擊殺標籤在 main.js onEnemyKilled 一處決定；新標籤的分值先用卡上的第一版，記 DECISIONS。
- 風格層 src/style.js 只管渲染。新加進場景的東西要過 game.style.dress()；人物姿勢經 characters.js KEY_POSES 與 style.poseDue()；殘影用 style.snapshot(rig, 顏色)。?style=off 必須玩起來完全一樣。人物動作 ② 的姿勢是資料，worn 模型靠 skin.js 的 IK 手到握點，方塊人同樣要對。
- 鏡頭與遮擋：level.js 的 cut（cut-away 著色器 uniform）與 fade（maps.js `fade`）每幀由鏡頭和玩家位置更新；議事亭是平塗畫風（look: 'flat'，postfx.js EdgePass 畫線），洞邊會被畫成線，改洞或淡出時兩種畫風都要看。
- 音樂是資料（src/music.js SONGS，voice 表是合成聲），audio.js 播；settings.js 的 song 選曲，?music= 優先。不加音檔，除非開新卡。
- 每張地圖有渲染預算（maps.js budget；夜店 400 次繪製最緊）。超出就減東西，不要調高預算；新地圖量度後寫入自己的預算。
- 不加執行期依賴；不碰 senado/；不換引擎；repo 裡不放密鑰與個人資料；commit 與程式不寫模型名。福隆新街的店名、招牌、人名全部虛構。

## 寫測試要避開的坑（之前 CI 紅過或本機反覆過的原因）
- 不要斷言取決於隨機冷卻的時間點。用固定種子（?seed=）並逐格檢查狀態。
- 擺位後先把被擺位過程影響的狀態重設，再開始量度（敵人用 e.update = () => {} 定住；殺戮鏡頭與停格會改時間倍率，量子彈飛行前先清掉 killcamT、hitstopT、焦點）。測試裡自己發的子彈要給它飛的時間：60 m/s 在 120 Hz 一步飛半米，4 米要 8 步以上才算中。
- 敵人生成後有一段 spawnLock，期間子彈穿過；測試先等它過去或設為 0。
- page.reload() 之後 window.game 是 <div id="game"> 直到 main.js 接手：先 waitForFunction(() => window.game && typeof window.game.startRun === 'function') 再用。
- 開兩個頁面的測試，先停掉第一個頁面的畫面循環（g.frame = () => {}）；頁面在 try/finally 裡關閉。設定存在 localStorage，同一個瀏覽器環境裡會跨頁面留下，測試完要 reset。
- 量「轉身速度」時把目標放在正後方，量「走速」時先清掉舊路徑（boss.path = null）；頭目在玩家前 1.7 米就停，撞飛玩家的測試要用會穿過玩家的那段衝刺。
- 不要用 Date.now 或系統時鐘決定測試結果；每日挑戰的測試要能注入日期。
- 地圖驗證器（test/maps.test.mjs）會對每張地圖跑；改地圖資料後先本機跑它。音樂的測試用 OfflineAudioContext 渲染，新曲的貝斯、鍵盤、主旋律要在底鼓 12 dB 之內。
- 未完成的測試草稿不要放進 test/。

1. 開新對話，把「短版」框內全文貼進 /goal（全文超過 4,000 字元的上限），它會讀「完整工作規矩」，由 docs/TASKS.md 未打勾的卡接着做，次序如框內「次序」一節。
2. PR 就是進度表；隨時可以手動停止。想線上試就說「開 PR 直接合併吧」，它會合併進 main 並等 Pages 部署完回報。
3. 前三張（議事亭視線、頭目每場景一次、人物動作 ②）各是半天到一天；做完一張就值得試一局再讓它繼續。
