HOW TO USE THIS FILE

This file holds 14 image requests for the comic-panel cutscenes we have been making in this conversation: the rest of the main story. All the earlier reference images are already in this conversation above.

The story has changed. Jing Jing, the young film star, is now the true villain: the hero once upstaged her in a film by dying too beautifully, so out of jealousy she flattered the gang boss into making the hero the prey of his deadly reality show, and she makes no secret of it. She is beautiful but unforgivable, and she is no fighter: she shoots from behind and lets others fight for her. If you drew any of these pages before, the requests marked CHANGED or NEW replace them; the ones marked unchanged are the same as before.

1. Draw exactly ONE image per reply, in the order below. Start with REQUEST 1 now.
2. After each image, stop and wait. When I write "next", draw the next request. When I write "skip", do not draw the next request: pass over it and wait again (the request after it becomes the next one). When I write "redo" and a note, redraw the last image with that change.
3. Never put two requests into one image, and never draw any words from this file into an image.
