## 1. 而家的問題

**量度（2026-11-02）：** `npm run measure -- --mode danmaku --god --loot`，種子 101–105，五局全部通關，平均 9.1 分鐘。

- 頭目戰平均 **5–9 秒**，幾乎冇受傷；最長一次係第三層刀后，26 秒、受傷 24。

- 頭目的血按命中次數計：4 下一格，即係 16–20 粒子彈，用咩槍都一樣。

**開發者打過的感覺（11-02）：** 冇子彈時間的反制。刀后舉刀嗰 0.5 秒有得踢、有得用鑊打返粒子彈，係唯一有特色的；重炮、鐵盾淨係繞去背脊射；長鏡同選角陳淨係靶。

## 2. 共通規則（全部頭目）

### 2.1 血量按傷害

- 頭目有 `hp`，子彈照每支槍的 `damage` 扣（散彈每粒照計）。血條照分格，但格只係刻度。
- 唔係子彈的嘢定一個固定傷害（第一版）：身邊爆炸 25、踢 5、鑊 10、踢人撞埋去 8。
- **反制另計**，一次大約係頭目血的一成半至兩成半（§2.4）。

| 頭目 | 血（第一版） | 備註 |
|---|---|---|
| 部門頭目 | 200 | 第二層 ×1.25 即 250，跟普通敵人每層加厚（`config.js` `ENEMY_HP.perStage`） |
| 長鏡＋選角陳 | 長鏡 110、選角陳 130 | 暫定 |
| 金爺 | 360 | 第一階段 240，第二階段 120；暫定 |
| 晶晶 | 「佢的戲」240 | 唔係佢條命（9527 唔殺佢） |

**點計：** 每支槍每秒的傷害大約係雙槍 9、散彈 15、衝鋒槍 17、步槍 18、機槍 22。頭目郁得多、有遮擋，淨係射，一場大約打得出每秒 3 點左右，即係 200 血要成分鐘以上；識反制，三四次反制已經扣咗大半，就係 45 秒左右。

### 2.2 一局入面點樣排

- 第一、二層：喺四場部門頭目入面抽（刀姐、炮哥、門神、長鏡＋選角陳），**一局唔重複**。
- 第三層：**固定金爺**，喺戲棚。
- 真結局：已經通關兩次之後，打低金爺就入天光，再打晶晶（§5）。
- 每個頭目一個自己的片場（DECISIONS 2026-10-30）。片場先做玩法要的格局，美術跟 Godot。
- 入場：第一次撞到出成頁分鏡，之後只出名牌格約 1.5 秒；倒下蓋「某某　殺青」印。血條上的名改用劇本的名。
- 頭目房前面嗰波普通敵人：**照留**（開發者 11-03）；第一波打手下，第二波先係頭目。
- 全部快彈、紅線預告、彈幕有缺口：同普通房一樣。頭目照舊抓唔到做人盾，佢叫出嚟的手下抓得到。

### 2.3 每個頭目都要有

- **一句特色**：由劇本的身份同口頭禪嚟。
- **兩三招**：每招有預告，彈幕有缺口。
- **兩三個反制**（§2.4）。
- **一個專屬花招**：入花招手冊（`src/codex.js`）。

### 2.4 反制

**反制**：頭目的招牌招式有一個好短的時機，玩家有意識去做一個動作，就將嗰招反過嚟打佢。

| 規矩 | 點做 |
|---|---|
| **時機短，慢鏡先睇得清** | 時機全速大約 0.15–0.3 秒；開子彈時間（世界 ×0.2）就變成大約 1 秒。時機開始嗰下有一下閃光（刀身、炸藥背囊、甲扣、瞄準鏡、籌碼、反射面）：全速只係閃一下（約 0.1 秒），開子彈時間先睇得清（約半秒） |
| **做成扣大血** | 一次約頭目血的一成半至兩成半，仲有僵直，跟住係一個打得入的空檔 |
| **回專注** | 反制成功回 0.25 專注（同處決一樣，`FOCUS.executeRefill`）：用啱時機開慢鏡，慢鏡自己還返 |
| **唔鎖血** | 唔反制都打得死，只係慢（大約成倍時間）。例外：門神的甲（§3.3），甲本身就係由反制卸 |
| **每個頭目唔同** | 刀姐靠拆招（近身時機）；炮哥靠推擲彈兵做人肉炸彈；門神靠卸甲；長鏡靠對鏡；選角陳靠踢槍；金爺靠射籌碼；晶晶靠環境多次反彈 |
| **有名、有分、入手冊** | 每個反制一個 Style 名同分，第一次做到點亮手冊 |
| **失手有代價** | 時機錯咗就係食咗嗰招 |

遊戲而家已經有的，係呢套的基礎：用子彈打中子彈（DEFLECT）、鑊揮嘅頭 0.25 秒打返子彈（HOME RUN、狙擊彈 GONG）、踢返敵人的手榴彈、半空射爆手榴彈（AIRBURST）、旋轉避斬、子彈時間飛撲、踢翻枱、抓人做人盾同推出去。

## 3. 四個部門頭目

冇第二階段。每個 45 秒左右（識反制），血 200（第二層 250）。

### 3.1 刀姐（動作指導，酒樓大廳）——「你點死，我度好晒。」

**特色：一場近身的刀戰，佢度好晒點殺你，你要拆佢的招。** 遠距離唔再射子彈，係**真正的飛刀**。每一招之前，畫面一角彈出一格分鏡草圖做預告（「第三種：飛刀」「第七種：衝刺斬」）。

| 招 | 做法 |
|---|---|
| 飛刀 | 高台上紅線 0.4 秒，兩排飛刀，第二排插喺第一排之間。飛刀係一把刀的樣，喺半空轉，刀身用敵人子彈的功能色（黃白）；中唔到你就釘喺枱、牆、地上（只係畫面，拎唔起）。數同速度照而家（每排三把、24 米每秒），只係唔再係子彈的樣 |
| 衝刺斬 | 衝埋嚟停喺 1.7 米外，舉刀 0.5 秒，斬（而家有） |
| 刀陣 | 落台時一圈飛刀，有缺口（而家有，改做刀的樣） |

| 反制 | 點做 | 效果 |
|---|---|---|
| **拆招**（近身） | 佢舉刀嗰 0.5 秒踢佢（而家有） | 佢彈開、空檔長咗；加：20 |
| **旋轉穿過**（子彈時間） | 佢斬落嚟最後一刻（刀光閃嗰下）旋轉穿過佢，轉到佢背後 | 佢背脊空 1 秒，嗰一秒傷害 ×2；佢踉蹌，要重新上台 |
| **射落飛刀** | 子彈打中飛刀（而家的 DEFLECT） | 唔扣佢血，但回專注；一排射齊三把係「落刀」 |

- **唔做（11-02）：** 撳 G 接刀、執刀擲返佢：難度太高。
- **可選：「冇度過」**（第一稿）：佢記住你上次點避，下次封住嗰種避法；你用佢未見過的方法避開，佢呆一秒。可以第二步先加。
- **專屬花招：** 旋轉穿刀 BLADE WALTZ（旋轉穿過佢一斬）。
- **同而家比：** 招式照用；遠距離改做真飛刀；加旋轉穿過、拆招扣血。

### 3.2 炮哥（爆破組，貨櫃碼頭）——「今晚冇假炸藥。」

**特色：佢身邊有源源不絕的炸藥，就係佢的擲彈兵。你抓一個做人盾，推出去撞炮哥，背囊就喺佢身上爆；炮哥見你抓住一個，就用佢的機槍搶先射爆你手上嗰個。** 同刀姐分得開：刀姐係一對一拆招，炮哥係頂住火力送人肉炸彈。

| 招 | 做法 |
|---|---|
| 轉輪機槍 | 起轉 0.8 秒（槍管轉、聲、紅線），之後一扇快彈掃過去（而家的掃射同扇） |
| 迫擊砲 | 一次三發，每發落點一個紅圈（而家有） |
| 叫擲彈兵 | 場上擲彈兵少過兩個，每 8 秒左右由貨櫃後面行出一個（再生的炸藥）；擲彈兵照常拋手榴彈（而家的擲彈兵） |
| 射爆人盾 | 你抓住一個擲彈兵，炮哥就轉瞄佢背囊：紅線 0.6 秒，之後一梳子彈；背囊中咗就喺你手上爆 |

| 反制 | 點做 | 效果 |
|---|---|---|
| **人肉炸彈**（近身） | 抓擲彈兵做人盾，行近，推出去撞炮哥（而家的人盾推出去） | 背囊喺佢身上爆：40，鋼板歪咗，正面都打得入 2 秒 |
| **趕喺佢射之前推**（子彈時間） | 炮哥紅線對住你手上的擲彈兵（背囊閃），喺紅線完之前推出去 | 推得切：人肉炸彈照中；推唔切：背囊喺你手上爆，你受傷、佢冇事 |
| **踢返手榴彈** | 擲彈兵拋過嚟的手榴彈，踢返去炮哥度，或者喺佢頭上射爆（而家的踢返、AIRBURST） | 喺佢身邊爆：25 |

- **擲彈兵做人盾**（開發者 11-03 定，全部擲彈兵）：推出去撞人就爆，俾子彈打中背囊就喺你手上爆（`REDESIGN` §5 #8）。普通房一樣用得：抓擲彈兵推入人堆，係一個新花招。
- **專屬花招：** 人肉炸彈 SPECIAL DELIVERY（推擲彈兵喺炮哥身上爆）。
- **同而家比：** 鋼板、掃射、迫擊砲照用；加擲彈兵再生同人肉炸彈，同佢搶先射爆人盾。

### 3.3 門神（場務，海底隧道口收費廣場）——「清場！生人死人都唔准過！」

**特色：佢全身重甲加一面大盾，平時子彈射唔穿（火花、「叮」）。要反制先卸到佢的甲：卸甲之後，佢輕咗、快咗、狠咗。** 佢唔追你，守住出口（隧道口）。

| 招 | 做法 |
|---|---|
| 盾撞 | 舉盾 0.7 秒，衝 7 米（而家有）；衝嘅時候會慢慢轉向跟你 |
| 撼盾 | 盾撼落地，一條裂地沿行車線衝向你（紅線 0.7 秒），要打橫避；之後個盾插喺地 1.4 秒 |
| 清場 | 對講機一叫，兩個盾牌保安由隧道口並排推出嚟（人牆） |
| 左輪 | 你喺遠處，佢由盾邊開三槍（而家有） |

**卸甲（兩步：重甲、盾）：**

| 反制 | 點做 | 卸咗乜 |
|---|---|---|
| **鬥牛**（子彈時間） | 佢盾撞衝到最後 0.3 秒先打橫閃（太早閃佢會轉向跟住你），佢衝過龍撞落收費亭或者欄杆；撞嗰下甲扣閃 | **重甲**甩落地，唔會再著返：30，之後身體打得入（盾照擋正面） |
| **撬盾**（近身） | 盾插喺地嗰 1.4 秒，踢盾邊 | **盾**跌落地：20。佢會行返去執，3 秒；你踢遠個盾佢要行耐啲，執返就返原 |
| **近身卸甲**（近身） | 佢僵直嗰陣（撞完、撬盾、俾人撞到）踢佢側面或者背脊（之後的近戰連擊一樣計）；甲扣閃嗰下中先算 | 每下甩一粒甲扣：三粒甩晒，**重甲**跌落地（同鬥牛一樣，唔會再著返）；鬥牛係一下卸晒，近身係三下慢慢卸 |

- **卸晒（重甲加盾都冇）：** 全身打得入；佢冇咗盾，改兩手揸左輪快射、走得快啲。呢個係佢最危險亦最脆弱的時候。
- **借人牆**：抓一個盾牌保安推佢撞門神，門神僵直 1 秒（而家「踢人撞埋去」照計），可以幫你造出鬥牛或者撬盾的機會。
- 甲係佢的特色，唔當鎖血：卸甲靠反制，唔靠解謎；而且第一次鬥牛或者撬盾通常喺開打 10 秒內就有機會。
- **專屬花招：** 鬥牛 MATADOR（門神撞落收費亭）；卸甲 DISARMED（重甲同盾都卸晒）。
- **同而家比：** 盾撞、左輪照用；由「正面免疫、打背脊」改做「全身甲，反制卸甲」；由追住你改做守門；加清場。

### 3.4 長鏡＋選角陳（攝影指導＋選角，攝影棚）——暫定

**開發者 11-02：要做完試手感先講得準。** 第二稿的設計留住做起點：

- **特色：** 一個揀位，一個影。選角陳追住你、用散彈同試鏡相將你趕埋「企位」；長鏡伏喺高處，紅線就係佢的取景框，鎖住你一秒就開槍。兩個都唔再係靶。
- **招：** 選角陳散彈（三條紅線 0.6 秒）、下一位（試鏡相落地變企位，踩中長鏡即刻鎖定）；長鏡對焦一槍（72 米每秒、40 傷害）；合招紅線衝鋒（而家有）。
- **反制（暫定）：**

| 反制 | 對 | 點做 | 效果 |
|---|---|---|---|
