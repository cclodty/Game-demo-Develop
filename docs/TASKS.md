# 任務清單

這是活的清單：每天從這裡拿一張任務卡給 Claude，做完打勾。階段目標和驗收關卡在 [ROADMAP.md](ROADMAP.md)。

## 任務卡怎樣寫

每張卡一天內做得完，一張卡一個 PR。照這個格式寫在下面，Claude 做完會把驗收標準逐項核對、附截圖。

```
### 任務名稱
- 目標：一句話，玩家會感受到什麼不同
- 涉及：大概會改哪些檔案
- 驗收：
  - [ ] 可以觀察到的結果 1
  - [ ] 可以觀察到的結果 2
  - [ ] npm run lint && npm test 通過；新行為有測試
- 這次不做：明確排除的東西
```
