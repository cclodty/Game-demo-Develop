# 任務清單

這是活的清單：每天從這裡拿一張任務卡給 Claude，做完打勾。階段目標和驗收關卡在 [ROADMAP.md](ROADMAP.md)；每張卡一個 PR，PR 的寫法照 [`.github/pull_request_template.md`](../.github/pull_request_template.md)。

## 任務卡怎樣寫

```
### 任務名稱（估計：半天 / 一天）
- 目標：一句話，玩家會感受到什麼不同
- 涉及：大概會改哪些檔案
- 驗收：
  - [ ] 可以觀察到的結果 1
  - [ ] 可以觀察到的結果 2
  - [ ] npm run lint && npm test 通過；新行為有測試
- 這次不做：明確排除的東西
```

三條規矩：

1. **一天做得完。** 估計超過一天就拆成兩張，寧可小。
2. **「這次不做」一定要寫。** 這是給 Claude 的欄杆：沒寫的話，它會把旁邊的東西也一併做了。
3. **驗收是看得到的結果**，不是「程式寫好了」。能寫成「按 X 之後會看到 Y」最好。

## 每天怎樣用

1. 開新對話，貼：「做 TASKS.md 的『卡名』」。Claude 會先複述驗收標準，不清楚的先問。
2. 做完會有 PR、截圖、測試結果。你玩十分鐘，覺得不對就按 N 記下，匯出貼回對話。
3. 滿意就合併、打勾；改了手感數字就在 [DECISIONS.md](DECISIONS.md) 加一行。
4. 一次只開一張卡。做不完就順延，不要同時開兩張。
