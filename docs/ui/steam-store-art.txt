HOW TO USE THIS FILE

This file asks for the pictures behind the game's Steam store and library images. It REPLACES the earlier Steam request in this conversation: we tried a detailed illustration of the hero firing two pistols, and it was too busy and his face read badly at thumbnail size. This time the style is a simple, mysterious graphic poster: the hero only as a white silhouette.

The game's name and logo are NOT drawn by you: they are added afterwards in the game's own fonts. So every picture must leave clean, dark space for the logo where the request says, and must contain no words at all.

1. Draw exactly ONE image per reply, in the order below. Start with REQUEST 1 now.
2. After each image, stop and wait. When I write "next", draw the next request. When I write "redo" and a note, redraw the last image with that change.
3. Never draw any words from this file into an image.

THE RULES FOR EVERY IMAGE

A graphic poster, not a busy illustration: flat shapes and lots of empty dark space, with a subtle screen-print grain. Only four colours: near-black indigo for the background, one deep theatre red, white, and small touches of warm gold. Crisp clean edges. It must read instantly when shrunk to a small thumbnail.

The hero, 9527, appears ONLY as a flat white silhouette: no face, no eyes, no skin tones and no shading inside the body, except a few thin dark lines that mark the jacket's edges and the loose tie, so he stays mysterious. His outline must still be recognisable: messy hair with one cowlick sticking up, a suit jacket one size too big flaring out, a loose tie flying, and a pistol in each hand (the pistols are solid black). He moves like a dancer, never like a soldier.

Bullets are small yellow-white dashes frozen in the air (bullet time). The setting, when it shows at all, is the bamboo-scaffold opera theatre, drawn only as faint dark-on-dark lines. No speech bubbles, no captions, no letters, words, numbers or logos anywhere. No real-world landmarks.
