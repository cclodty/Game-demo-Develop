# 第二次通關：背刺

2026-10-31 第二稿 · TASKS「故事 ⑥」· 依據 `docs/STORY.md` §3（晶晶、場務姐）、§5、§11。接住金爺倒下。

**第二稿（開發者 10-31）：** 第一稿入面，晶晶被逼補槍，喊住塞紙條俾 9527。開發者話唔係咁：

- **晶晶係真正嘅元兇。** 佢搶戲輸咗，妒忌又嬲，向金爺獻媚，主動要求揀 9527 做獵物，亦唔掩飾；靚，但唔值得原諒。
- **佢唔識打，所以係背刺。** 佢喺背後偷襲 9527，之後先講原因。
- **紙條改由場務姐塞。**

## 呢章要做到乜

- **9527 終於知道「點解係我」。** 序章佢唔飲孟婆湯，就係想知呢個答案；第二次通關由晶晶親口講出嚟。
  - 佢喺 9527 第一部戲死得太靚，搶咗晶晶嘅鏡頭。
  - 晶晶妒忌，所以揀佢做獵物。
- **輪迴學到嘢：** 9527 冇飲孟婆湯，記得大螢幕會跌落嚟，所以今次避開咗。點知死喺背後嘅晶晶手上。佢下一次就記得要轉身（真結局）。
- **閻王：「你心甘，但唔抵。」**
  - 心甘：佢終於知道點解係佢，冇遺憾。
  - 唔抵：死喺咁嘅人手上，唔值得。
- **晶晶嘅樣：** 靚、冷、得意。佢唔係打手，開槍都係細細一支手袋槍。佢最在乎嘅係鏡頭，殺完人第一件事係對住直播機擺甫士。
- **場務姐塞紙條：** 佢好似序章咁蹲低「點屍」、剔文件夾，順手將紙條塞入 9527 西裝袋，望都唔望佢。
- **連續性：** 金爺崩咗一隻金牙；9527 嘅領呔鬆咗。
