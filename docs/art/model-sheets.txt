HOW TO USE THIS FILE

This file holds 20 image requests: model sheets of the characters of the video game whose comic-panel cutscenes we have been making. They are drawn to be turned into 3D models: a 3D generator will read the front, left and back views of each character. They are not cutscene pages, so none of the cutscene rules apply here: no panels, no dark background, no drama. The reference images named in each request are the 9527 character sheet, the boss lineup sheet and Jing Jing's character sheet from the cutscenes; if they are not already in this conversation, I attach them now.

1. Draw exactly ONE image per reply, in the order below. Start with REQUEST 1 now.
2. After each image, stop and wait. When I write "next", draw the next request. When I write "skip", do not draw the next request: pass over it and wait again (the request after it becomes the next one). When I write "redo" and a note, redraw the last image with that change.
3. Never put two requests into one image, and never draw any words from this file into an image.

THE RULES FOR EVERY MODEL SHEET

- A 3:2 landscape image on a plain, flat, light grey background: no gradient, no floor, no ground shadow, no vignette.
- The same character three times, side by side, evenly spaced, nothing overlapping or touching: on the left the FRONT view; in the middle the LEFT SIDE view (the character's own left side towards us, so the character faces the left edge of the image); on the right the BACK view. All three exactly the same height and scale, the feet on one shared line, the whole body visible from the top of the head (or hat) to the soles of the shoes, with a clear margin all round.
- The same neutral A-pose in all three views: standing straight; arms straight and lowered about 45 degrees from the shoulders, held away from the body so the armpits and the sides of the body are clearly visible; hands open and empty, fingers together, palms facing the thighs; legs straight, feet a little apart, toes pointing forward; head level, looking straight ahead; a neutral expression.
- The same modern Japanese anime look as the cutscenes, but drawn as a reference for a 3D modeller: bold flat colours with only very soft, minimal shading; no black ink outlines (at most very thin, light lines); no cast shadows, no screentone, no rim light, no glow, no speed lines. About 6.5 heads tall.
- Only the character: no weapons, shields, bags, cigars, papers or other props in the hands or strapped on, unless the request asks for them; the game adds those as separate models. Clothes close enough to the body that the arms and the legs are clearly separate; no long scarves, capes or loose ribbons.
- Colours: each character keeps one main colour that reads from above (on the head or hat, the shoulders and the back), because the game is seen from a high camera. Only the hero, 9527, wears white. No character uses bright yellow, cyan or pure red as a main colour: those are the colours of the bullets and the laser sights in the game. The gang's colour is a dark, brassy gold: where a request mentions gold, keep it dark and brassy and use it only as small accents; where it does not, add none.
- No text, letters, numbers, labels, arrows, measurements, logos or colour swatches anywhere.
- Original characters that do not resemble any real person or actor.
