# 大三巴牌坊 Ruins of St. Paul's：量體研究

**狀態：工具跑通，研究未寫。** 這一頁由「大三巴：量體研究」那張卡寫完（十項，見 `massing/README.md`）。現在只有 OSM 抽取、量體和平面圖（`plan.svg`），和抽取時看到的幾件事。

## 已有的資料

- `site.json`：原點在牌坊立面中點以南 21.6 米，是現在手建地圖的原點對得上實景時的位置（現有地圖的立面線 z = −21.6）；旋轉 −0.9°，令立面沿遊戲的 x 軸。
- `data/osm_raw.json`：2026-10-22 由 OSM API 抽取，原點四周 ±220 米。
- `data/massing.json`：1,032 棟樓（557 棟有 OSM 的 `height`，5 棟由層數推算，470 棟估算或當作小亭），285 條路，49 段石階。
- `plan.svg`：紅色是現在的遊戲地圖，藍色虛線是它的可玩範圍。
